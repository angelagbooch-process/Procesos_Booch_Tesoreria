# Formularios Streamlit — Levantamiento de funciones de Yorlenis

## Contenido
- `app.py`: aplicación de formularios y borrador de procedimiento.
- `requirements.txt`: dependencia para instalar Streamlit.

## Cómo ejecutarla
1. Instale Python 3.10 o posterior.
2. Abra una terminal en la carpeta donde se encuentran los archivos.
3. Instale dependencias:
   `pip install -r requirements.txt`
4. Inicie la aplicación:
   `streamlit run app.py`
5. Se abrirá una pestaña del navegador con los formularios.

## Uso
- Seleccione la función en la barra lateral.
- Responda las preguntas.
- Pulse “Generar / actualizar borrador”.
- Revise el borrador y corrija el texto si hace falta.
- Descargue el procedimiento TXT y las respuestas CSV antes de cerrar.

## Importante
Esta es una versión piloto. No guarda automáticamente las respuestas en una base de datos. Si se va a enviar a Yorlenis desde otro equipo, hay que publicar la aplicación en un servicio accesible o ejecutarla en un equipo servidor con acceso de red. No comparta públicamente información financiera sensible sin acordar antes quién puede acceder a ella.
